# 上傳區

把 **Numbers（.numbers）** 或 **CSV** 檔上傳到這個資料夾，就會自動匯入網站。

## 怎麼上傳

1. 在 GitHub 打開這個資料夾（`data-import/inbox`）
2. 右上角 **Add file → Upload files**
3. 把 `.numbers` 檔拖進來 → 按 **Commit changes**
4. 到 repo 的 **Actions** 分頁看「試算表匯入」：
   - ✅ 綠燈：匯入成功，約 1–2 分鐘後網站更新
   - ❌ 紅燈：點進去看 Summary 的錯誤說明，修正後重新上傳

處理完的檔案會自動移到 `done/`（成功）或 `failed/`（失敗），報告存在 `reports/`。

## 表格格式

第一列是欄位名稱，可以有多個工作表（例如每個縣市一個工作表）。

| 欄位 | 必填 | 說明 |
|---|---|---|
| 店名 | ✅ | |
| 縣市 | ✅ | 高雄市、台南市、嘉義縣…（工作表名稱若是縣市，會用來檢查打錯的縣市） |
| 區 | ✅ | 鹽埕區、新營區、恆春鎮…，網站上沒有的會自動新增 |
| 地址 | ✅ | 可以只寫路名門牌，會自動補上縣市與區 |
| 營業時間 | | |
| 店休日 | | 會併到營業時間後面，例如「10:00–20:00（週一公休）」 |
| 特色料理 | | 會成為店家介紹「招牌：…」 |
| 分類 | | 可以填自己的分類（例如「牛肉湯」「越南料理」），會自動對應網站分類並保留成標籤；沒填會依店名與特色料理判斷 |
| 品嚐日期 | | 日期會成為複核日期；填 ＊＊＊＊ 這類評分會存成內部備註 |

也可以加這些欄位：電話、價位（$～$$$$）、標籤、店家介紹、網址代號、細分類、分級、緯度、經度、分級理由。

## 規則

- **已經在網站上的店（同縣市同店名）會跳過**，不會覆蓋。要修改既有店家請用 `/admin` 後台。
- 匯入的店家分級一律是「待評鑑」，請到 `/admin` 評定分級。
- 有任何錯誤就**整批不匯入**，不會只匯入一半。
- 自動分類的關鍵字在 `data-import/category-rules.json`，可以自行增修。
